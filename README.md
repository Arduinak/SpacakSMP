# 🛌 Spacak SMP BedWars

## 🇸🇰 O projekte

**Spacak SMP BedWars** je unikátny Minecraft projekt, ktorý kombinuje klasický **BedWars** s prvkami **modovaného SMP servera**.

Projekt obsahuje:

* 🏗️ Kompletný build servera
* ⚙️ Nastavenia servera (configs)
* 🔓 Open-source prístup
* 💸 Úplne zadarmo (free to use)

Server je postavený na **Ketting software**, ktorý umožňuje kombináciu pluginov a modov pre maximálnu flexibilitu.

---

## ✨ Funkcie

* 🛏️ Vylepšený BedWars gameplay
* 🌍 SMP prvky (survival mechaniky)
* 🔧 Podpora modov aj pluginov
* 🏰 Vlastné mapy a buildy
* 📂 Kompletný server setup dostupný na stiahnutie

---

## 📦 Obsah repozitára

* `/server` – základ servera
* `/plugins` – pluginy
* `/mods` – módy
* `/configs` – konfigurácie
* `/world` – mapy a buildy

---

## 🚀 Ako spustiť server

1. Nainštaluj si Java (odporúčaná verzia podľa servera)
2. Stiahni alebo klonuj repozitár:

   ```bash
   git clone https://github.com/your-repo/spacak-smp-bedwars.git
   ```
3. Spusti server pomocou `.bat` alebo `.sh` súboru
4. Pripoj sa cez Minecraft klienta

---

## 🛠️ Použitý software

* **Ketting (Forge + Bukkit hybrid)**
* Minecraft modding API
* Plugin systém (Spigot/Bukkit kompatibilita)

# 🛌 Spacak SMP BedWars

## 🇬🇧 About the Project

**Spacak SMP BedWars** is a unique Minecraft project that combines classic **BedWars** with features of a **modded SMP server**.

The project includes:

* 🏗️ Full server build
* ⚙️ Server configuration files
* 🔓 Open-source access
* 💸 Completely free to use

The server is built on **Ketting software**, allowing both mods and plugins to work together.

---

## ✨ Features

* 🛏️ Enhanced BedWars gameplay
* 🌍 SMP survival elements
* 🔧 Support for mods and plugins
* 🏰 Custom maps and builds
* 📂 Full server setup available
